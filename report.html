http://paypal-secure-login.xyz/verify/account

Critical — 82/100 Likely phishing — do not visit / do not trust

  • [HIGH] URL-BRAND-IN-DOMAIN (+35) — Brand 'paypal' embedded in a non-brand domain
    'paypal-secure-login' contains the brand name but the site is not paypal's — e.g. paypal-secure.com is not PayPal.
    Fix: A brand name inside a longer domain name does not make it the brand's site.
  • [MEDIUM] URL-SUSPICIOUS-KEYWORDS (+15) — Suspicious keywords in URL: account, login, secure, verify
    login / verify / secure / account language in the URL is typical of credential-harvesting pages.
    Fix: Go to the service's official site instead of following a 'verify your account' link.
  • [MEDIUM] URL-SUSPICIOUS-TLD (+12) — Suspicious TLD: .xyz
    .xyz domains are cheap/free and disproportionately used for phishing kits. A legit site can use one, so this is only a supporting signal.
    Fix: Combine with the other findings; a .xyz login page for a major brand is a red flag.
  • [MEDIUM] URL-NO-HTTPS (+10) — Plain HTTP, no TLS encryption
    The connection is not encrypted, so credentials can be intercepted. Most major sites enforce HTTPS everywhere now.
    Fix: Do not enter credentials on an http:// page.
  • [MEDIUM] URL-HIGH-ENTROPY (+10) — High-entropy host/path (4.27)
    Random-looking strings in the host or path are typical of auto-generated phishing domains and encoded payloads.
    Fix: A real brand domain is readable; random strings are not.
